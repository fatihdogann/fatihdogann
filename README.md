# Mehmet Fatih Doğan

Backend-focused full-stack developer. I design APIs, data models and access control, and build the web and mobile apps on top of them, including offline-first clients that sync with a server.

- **Backend:** Node.js (NestJS, Express, Hono), C# / ASP.NET Core, Python / Django
- **Frontend and mobile:** TypeScript, React, Next.js, Capacitor, Flutter
- **Data and infrastructure:** PostgreSQL, SQLite, Prisma, Docker

## Products

- **[Gridpen](https://gridpen.mehmetfatihdogan.com.tr)** — Tables, formulas, charts and notes on one canvas, built on Yjs CRDTs with local storage and optional sync over a Node.js/Hono API. · [Demo](https://gridpen.mehmetfatihdogan.com.tr/demo?node=finance) · [Showcase](https://github.com/fatihdogann/gridpen-showcase)
- **[Readflow](https://readflow.mehmetfatihdogan.com.tr)** — Local-first reading archive on Next.js and SQLite; summaries run through your own coding-agent CLI or MCP agent, with no LLM API key. · [Source](https://github.com/fatihdogann/readflow)
- **[TaskWork](https://taskwork.mehmetfatihdogan.com.tr)** — Offline-first planner for web, iOS and Android from one React codebase, synced through Supabase Auth and PostgreSQL access policies. · [iOS](https://apps.apple.com/app/id6817678838) · [Android](https://play.google.com/store/apps/details?id=com.mehmetfatihdogan.taskwork) · [Showcase](https://github.com/fatihdogann/taskwork-showcase)
- **[Kalite](https://kalite.mehmetfatihdogan.com.tr)** — Accreditation reporting that traces program outcomes back to assessment data; NestJS, Prisma and PostgreSQL with role-based access. · [Showcase](https://github.com/fatihdogann/kalite-showcase)
- **[Trader Defteri & Defter Terminal](https://defter.mehmetfatihdogan.com.tr)** — Trade journal with web and Flutter clients, plus a separate Next.js market workspace with backtesting that reads journal data without modifying it. · [Showcase](https://github.com/fatihdogann/trader-defteri-showcase)
