# Mehmet Fatih Doğan

Backend-focused full-stack developer. I design APIs, data models and access control, and build the web and mobile clients on top of them, including offline-first apps that sync with a server.

- **Backend:** Node.js (NestJS, Express, Hono), C# / ASP.NET Core, Python / Django
- **Frontend and mobile:** TypeScript, React, Next.js, Capacitor, Flutter
- **Data and infrastructure:** PostgreSQL, SQLite, Prisma, Docker

## Products

### Gridpen

Tables, formulas, charts and notes on one canvas; editing a table updates its linked charts. Documents are Yjs CRDTs, stored locally in IndexedDB and synced through an optional account API.

TypeScript · React · Yjs · Node.js / Hono · SQLite

[Website](https://gridpen.mehmetfatihdogan.com.tr) · [Demo](https://gridpen.mehmetfatihdogan.com.tr/demo?node=finance) · [Showcase](https://github.com/fatihdogann/gridpen-showcase)

### Readflow

Local-first archive for articles, documents and PDFs, with highlights and full-text search. Summaries run through your own coding-agent CLI or MCP agent, so no LLM API key is needed.

TypeScript · Next.js · SQLite (FTS5) · MCP

[Website](https://readflow.mehmetfatihdogan.com.tr) · [Source](https://github.com/fatihdogann/readflow)

### TaskWork

Tasks, calendar and habits that keep working offline. One React codebase runs on web, iOS and Android; optional account sync uses Supabase Auth and PostgreSQL access policies.

TypeScript · React · Capacitor · Supabase · PostgreSQL

[Web app](https://taskwork.mehmetfatihdogan.com.tr) · [App Store](https://apps.apple.com/app/id6817678838) · [Google Play](https://play.google.com/store/apps/details?id=com.mehmetfatihdogan.taskwork) · [Showcase](https://github.com/fatihdogann/taskwork-showcase)

### Kalite

Accreditation reporting for MÜDEK/FEDEK that traces program outcomes back to assessment data. Includes role-based access, Argon2id password hashing and PDF/Excel evidence packages.

TypeScript · React · NestJS · Prisma · PostgreSQL

[Website](https://kalite.mehmetfatihdogan.com.tr) · [Showcase](https://github.com/fatihdogann/kalite-showcase)

### Trader Defteri & Defter Terminal

A trade journal with risk and discipline tracking, and a separate market workspace for charts, watchlists, news and backtesting. The terminal runs as its own service and reads journal data without modifying it.

Node.js / Express · PostgreSQL · Flutter · Next.js · Docker

[Website](https://defter.mehmetfatihdogan.com.tr) · [Showcase](https://github.com/fatihdogann/trader-defteri-showcase)

## Open-source tools

- **[RestoreLab](https://github.com/fatihdogann/restorelab)** — Tests whether a PostgreSQL backup actually brings an application back: restores it in Docker, then runs application checks separately from the restore. · [Sample report](https://mehmetfatihdogan.com.tr/assets/demos/restorelab-en)
- **[EMA Ses](https://github.com/fatihdogann/ema-ses)** — Turkish text-to-speech for macOS that runs offline after setup, with adjustable speed and WAV export. · [Screenshot](https://github.com/fatihdogann/ema-ses/blob/main/docs/ekran.png)
- **[turkce-utils](https://github.com/fatihdogann/turkce-utils)** — Turkish-aware casing, sorting, slugs and readability scores. Zero-dependency TypeScript library and CLI. · [npm](https://www.npmjs.com/package/turkce-utils)
- **[turkce-tarih](https://github.com/fatihdogann/turkce-tarih)** — Parses Turkish date expressions such as “yarın akşam 7’de”. Zero-dependency TypeScript library and CLI. · [npm](https://www.npmjs.com/package/turkce-tarih)
