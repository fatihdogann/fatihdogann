# Proje README şablonu

Her depoda ilk bakışta üç bilgi görünür: proje hangi işi yapıyor, nereden görülebilir, nasıl denenir? Metni projenin dilinde yaz. İki dil varsa README’leri birbirine bağla.

```markdown
# Proje adı

[Canlı site / örnek / paket](...) · [İkinci dil](...)

Kimin hangi işini çözdüğünü bir veya iki cümleyle anlat.

![Sonucu gösteren ekran görüntüsü](docs/images/ornek.webp)

## Hızlı başlangıç

Gerekenleri ve ilk çalışan komutu veya kullanım adımını ver.

## Özellikler ve sınırlar

Öne çıkan davranışları ve kullanıcıyı etkileyen sınırları belirt.

## Teknoloji ve mimari

Okuyucunun projeyi anlamasına yardım eden kararları anlat.
```

- **Canlı ürünün tanıtım deposu:** Canlı bağlantı, ekran görüntüleri, kısa teknik mimari. Kaynak kod yayımlanmıyorsa kurulum bölümü çıkar.
- **CLI veya npm paketi:** Ekran görüntüsü yerine kopyalanabilen komut ve çıktısı. Tarihe bağlı örneklerde referans zamanı sabitle.
- **Yerel uygulama veya eski proje:** Gerçek çalışma ortamını ve gereksinimleri yaz. Canlı adres yoksa bu bağlantıyı atla. Ekran görüntüsünde örnek veya sentetik veriler kullan.
- **About:** Tek cümleyle işlevi anlat. Website alanına gerçek siteyi, paket sayfasını veya projenin kendi portfolyo sayfasını koy. Konuları ana teknoloji ve kullanım alanıyla sınırla.
